# PickBazar Clone 🛒
[![PickBazar Clone](./images/PickBazar%20Banner.png)](https://yusra230.github.io/Pickbazar/)
A responsive, multi-page frontend clone of [PickBazar](https://pickbazar-react-rest.vercel.app/), built as part of my capstone project. The website recreates the original platform's layout and shopping experience with a focus on clean UI, responsive design, and consistent styling.

## Live Demo

[View Live Website](https://yusra230.github.io/Pickbazar/)

## Project Overview

This project is a frontend implementation inspired by PickBazar, featuring multiple pages with a consistent design and user-friendly navigation.

### Pages Included

- **Home:** Main landing page with a shopping-focused layout.
- **Offers:** Dedicated page for promotional offers.
- **Contact:** Contact page layout.
- **Authors:** Authors information page.
- **Help:** Help and support page.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap
- JavaScript

## ✨ Features

- Responsive layouts for different screen sizes.
- Multi-page website structure.
- Consistent styling and navigation.
- Clean and user-friendly interface.
- Reusable Bootstrap components.
- Interactive UI elements using JavaScript.

## Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone (https://github.com/Yusra230/Pickbazar.git)
```

**2. Navigate to the project directory**

```bash
cd pickbazar-clone
```

**3. Run the project**

Open `index.html` in your browser.

## Deployment

The website is deployed using **GitHub Pages**.

## Project Purpose

The goal of this project was to strengthen my frontend development skills by recreating an existing e-commerce website, practicing responsive layouts, working with Bootstrap, and building a structured multi-page user interface.
